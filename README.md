# 野球拳 YAKYUKEN

用攝影機辨識你出的拳（石頭 / 剪刀 / 布），跟美咲玩昭和綜藝風的野球拳。
電腦（橫式）和手機（直式、橫式）都可以玩。

## ▶ 線上直接玩

**https://hankhsu1969.github.io/yakyuken/**

電腦、手機都直接開這個網址就能玩（https，攝影機可用）。

## 在自己電腦上跑

### 電腦
雙擊 `start.bat`（需要已安裝 Python），瀏覽器會自動打開 `http://localhost:8765/`。

### 手機
1. 手機和電腦連**同一個 Wi-Fi**。
2. 在電腦上雙擊 `start_phone.bat`，會跳出一張 QR code 並在視窗裡顯示網址（例如 `https://192.168.0.151:8443/`）。
   Windows 防火牆若跳出詢問，請按「允許存取」。
3. 用手機掃 QR code 打開。第一次會出現憑證警告（因為是自己電腦產生的憑證）：
   - Android Chrome：「進階」→「繼續前往」
   - iPhone Safari：「顯示詳細資訊」→「造訪此網站」
4. 允許使用相機就可以玩了。手機要用 https 網址才能開相機，所以一定要用 `start_phone.bat`。

## 怎麼玩

1. 按「📷 開啟攝影機」，允許瀏覽器使用攝影機。
2. 在「出拳測試」畫面確認 ✊ ✌️ ✋ 都能正確亮起，再按「野球拳、開始！」。
3. 跟著喊「アウト！セーフ！よよいの **よいっ！**」，在「よいっ！」的瞬間對著鏡頭出拳。
   - 平手會接著喊「あいこで しょっ！」再出一次。
   - 沒偵測到出拳（手不在鏡頭裡、沒按鈕）這局不算，整局從頭重來。
   - 每贏一次美咲就脫一件（帽子 → 外套 → 球衣 → 球褲），先贏 4 次就完全勝利。
   - 你輸 4 次就出局。

### 按鍵 / 按鈕

| 操作 | 功能 |
|---|---|
| `1` / `2` / `3`（或 `Z` / `X` / `C`） | 石頭 / 剪刀 / 布 |
| 畫面上的 ✊ ✌️ ✋ 按鈕 | 手機或不用攝影機時出拳 |
| `M` / 🔊 | 靜音 |
| `F` / ⛶ | 全螢幕 |
| `Space` / `Enter` | 開始 / 再玩一次 |

### 辨識小技巧

- 手要完整入鏡，**手指朝上**，手心或手背對鏡頭都可以；不要讓手指直接指向鏡頭。
- 光線充足、背景單純會比較準。
- 剪刀可以用「食指＋中指」或「拇指＋食指」。
- iPhone 開靜音模式時遊戲會沒有聲音。

## 檔案

```
index.html          遊戲主頁
css/style.css       畫面樣式（橫式 16:9 舞台／直式手機版面、昭和綜藝風字幕、紅白幕轉場）
js/main.js          遊戲流程
js/hand.js          MediaPipe 手部關鍵點 → 石頭 / 剪刀 / 布
js/audio.js         Web Audio 即時合成的配樂（銅管、和弦、弦樂、貝斯、鼓組、太鼓）與音效
assets/*.jpg        H站（Higgsfield, GPT Image 2）產的角色圖
assets/voice/       H站（Seed Audio）產的日文語音
server.py           本機伺服器（--https 給手機用，會自動產生自簽憑證到 cert/）
start.bat           電腦版啟動
start_phone.bat     手機版啟動
```

需要網路：手勢辨識模型（MediaPipe）和字型是從 CDN 載入的。
